# 🍝 Ciao Bella | Gujranwala

A modern and responsive restaurant website designed for **Ciao Bella, Gujranwala**.  
This project focuses on creating an attractive user interface, smooth user experience, and a mobile-friendly layout using modern frontend technologies.

## 📌 Project Overview

Ciao Bella is a frontend restaurant website that showcases a clean and elegant design for a food business. The goal of this project was to practice responsive web design, UI development, and interactive features using JavaScript.

## ✨ Features

- ✅ Modern and clean restaurant UI
- ✅ Fully responsive design
- ✅ Attractive hero section
- ✅ Restaurant menu showcase
- ✅ Interactive JavaScript functionality
- ✅ Smooth animations and transitions
- ✅ Mobile and desktop friendly layout
- ✅ User-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Web Design
